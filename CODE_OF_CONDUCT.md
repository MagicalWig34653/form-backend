# Verhaltenskodex

Wir wollen eine respektvolle, einladende Zusammenarbeit. Kurz gesagt:

- Sei freundlich und sachlich; kritisiere Code und Ideen, nicht Personen.
- Keine Belästigung, Diskriminierung, Herabwürdigung oder persönliche Angriffe, weder öffentlich noch privat.
- Veröffentliche keine privaten Informationen anderer ohne deren Einwilligung.
- Gehe von guten Absichten aus, frage nach, wenn etwas unklar ist, und nimm Einwände ernst.

Wer dagegen verstößt, kann ermahnt, aus Diskussionen ausgeschlossen oder gesperrt werden. Meldungen bitte privat an die Maintainer über GitHub (Security-/Moderationskontakt des Repositorys). Dieser Kodex orientiert sich am [Contributor Covenant](https://www.contributor-covenant.org/de/version/2/1/code_of_conduct/).
