# Dokumentationslandkarte

Stand der Ersterfassung: 25.10.2026. Dieses Verzeichnis im Repository ist die alleinige Source of Truth. Die anfängliche Desktop-Ablage ist eine historische Übergabekopie und wird nicht parallel gepflegt. Sessions müssen wegwerfbar sein; sämtliche fortsetzungsrelevanten Informationen sind im Repository zu dokumentieren (verbindlich: ANFORDERUNGEN.md).

| Dokument                  | Zweck                                                     |
| ------------------------- | --------------------------------------------------------- |
| ANFORDERUNGEN.md          | Bestätigte Wünsche, Umfang, Bestandsschutz                |
| ARCHITEKTUR.md            | Vorgeschlagener Aufbau und technische Grenzen             |
| FORMULARE-UND-ABLAEUFE.md | Definitionen, Module, Editor, SDK, Import/Export, MCP     |
| SICHERHEIT-UND-DATEN.md   | Verschlüsselung, Speicherung, Rechte, Debug und Statistik |
| MIGRATION.md              | Vollständige Migration und Kompatibilität                 |
| ENTWICKLUNG.md            | Claude, Sonnet, Haiku, Codex, effiziente Agent-Arbeit     |
| ARBEITSPLAN.md            | Empfohlene Umsetzung und nächste Pakete                   |
| STATUS.md                 | Tatsächlich erzeugt, geprüft, offen                       |
| OFFENE-ENTSCHEIDUNGEN.md  | Noch nicht entschiedene Produkt-/Technikfragen            |
| REFERENZEN.md             | Gelesene Quellen, nutzbare Vorbilder und Grenzen          |
| decisions/README.md       | Entscheidungsverzeichnis und ADR-Vorlage                  |
| handoffs/TEMPLATE.md      | Kompakte Paketübergabe                                    |

**Leseschlüssel:** „Bestätigt“ beruht auf einer ausdrücklichen Nutzervorgabe. „Vorschlag“ ist ein Architekturansatz und noch keine Freigabe seiner Einzelheiten. „Offen“ benötigt vor abhängiger Implementierung eine Entscheidung. Aussagen über die Altsoftware beruhen auf einer ersten lesenden Sichtung, nicht auf einem vollständigen Audit oder einer Produktionsprüfung.
